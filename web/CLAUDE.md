# web

Next.js 16 App Router console for ElasticClaw. Tailwind v4 (CSS-first, all theming in `app/globals.css`), shadcn/ui primitives in `components/ui/`.

Verify changes with `npm run lint`, `npm run typecheck` and `npm run build` from this directory.

All UI styling follows the Industry design system — read web/DESIGN.md before touching components.
